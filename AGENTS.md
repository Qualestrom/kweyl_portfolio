# Project Directives: Christopher Lamera Portfolio

> **Guiding Principle**: Uncompromising quality and empirical verification over speed. Never hand off unverified or broken code to the user.

## Mandatory Autonomous Critique & Refine Loop
Every coding, UI, styling, and architectural task in this repository must follow the self-contained execution loop:

```
[1. IMPLEMENT] ──> [2. COMPILE & BUILD] ──> [3. VISUAL CAPTURE] ──> [4. CRITIQUE] ──> [5. REFINE] (Loop until verified) ──> [6. SYNC & PUSH]
```

1. **Implement**: Code changes grounded in the Snezhnayan / Nod-Krai Frostmoon crystalline aesthetic.
2. **Build**: Run `npm run build` to confirm 0 errors/warnings.
3. **Capture**: Capture headless browser screenshots of mobile & desktop viewports to inspect actual live rendering.
4. **Critique**: Analyze typography, contrast (WCAG AA), optical balance, and celestial graphics clearance.
5. **Refine**: Automatically fix flaws and repeat the loop until the command is matched with high fidelity.
6. **Deploy**: Update execution logs, commit with conventional commit messages, and push to `origin/main`.
